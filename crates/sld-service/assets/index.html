First-time setup: connect your game

Point your game's telemetry export at this app, then confirm it below with the live tiles above.

  1. Make sure your wheel is plugged in over USB. Use the Test LEDs button below to confirm it's found before touching the game at all.
  2. In Forza (Horizon 5, Horizon 6, or Motorsport), go to Settings > HUD and Gameplay > Data Out and set:
    Data Out: On
    IP Address: 127.0.0.1
    Port: 5300
    Use the IP of this machine (the one running logitech-sim-led) on your network, not the game PC's IP. If the address above doesn't look right, run ipconfig (Windows) or ip addr (Linux/macOS) on this machine to find it, and make sure firewalls allow inbound UDP on the port above.
    Forza Motorsport also has a Data Out Packet Format setting -- set it to Dash, not "Sled", or you'll get RPM but no speed/gear/fuel.
  3. Get in a race. The RPM, Speed, and Gear tiles above should start updating live -- once they do, the wheel's LEDs should light up as you accelerate toward redline.
